# Judge-look (visual rebrand review)

Compare screenshots of the rebranded UI against the spec (brand.json + PLAN).

Report only clear mismatches: layout, order, alignment, spacing, sizes, colors,
borders, radii, type, exact texts. Ignore anything the spec leaves open (free),
states not shown, font anti-aliasing, and unreadable text.

Reply with MATCHES or MISMATCH list. Designer-supplied final assets replace
generated placeholders.
